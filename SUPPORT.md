# Support

Thanks for using ResumAI! Here's where to go for help.

## 💬 GitHub Discussions — questions & ideas

Use [Discussions](https://github.com/joaco-munoz/resumai/discussions) for:

- **Q&A** — "How do I configure DeepSeek?", "How do I deploy to Vercel?",
  usage and setup questions.
- **Ideas** — feature proposals and suggestions before they become issues.
- **Show and tell** — share your instance, templates, or providers you've wired up.
- **Provider integrations** — help and coordination for adding AI providers.

Please search first — your question may already be answered.

## 🐛 GitHub Issues — bugs & concrete feature requests

Open an [Issue](https://github.com/joaco-munoz/resumai/issues) for:

- **Bug reports** — something is broken and reproducible. Use the bug template.
- **Feature requests** — a specific, actionable capability. Use the template.
- **Documentation issues** — something is missing, wrong, or unclear.

Before filing, check the docs (start with the [README](./README.md) and
[docs/troubleshooting.md](./docs/troubleshooting.md)) and search existing issues.

## 🔒 Security

**Do not** report vulnerabilities in public issues. Follow [SECURITY.md](./SECURITY.md).

## ❓ What is not covered

This is a community-maintained open-source project provided **as-is** under the
[MIT License](./LICENSE). There is:

- **No SLA or guaranteed response time.** Maintainers and contributors help on a
  best-effort basis.
- **No commercial support** offering at this time.
- **No support for your third-party accounts** (OpenAI/DeepSeek billing,
  Supabase account issues, Flow.cl merchant setup) — contact those providers.

If you rely on ResumAI in production, self-hosting means you own operations,
security and data-protection responsibilities. See
[docs/self-hosting.md](./docs/self-hosting.md) and [docs/privacy.md](./docs/privacy.md).
