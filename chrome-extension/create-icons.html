🎨 Generador de Iconos ResumAI

Esta herramienta genera iconos temporales para la extensión de Chrome de ResumAI.

📋 Instrucciones de Uso

  1. Generar Iconos: Haz clic en "Generar Todos los Iconos" para crear los iconos.
  2. Descargar: Usa "Descargar Todos" para obtener un ZIP con todos los iconos.
  3. Instalar: Extrae los archivos en la carpeta chrome-extension/icons/
  4. Cargar Extensión: Ve a chrome://extensions/ y recarga la extensión.

📁 Archivos Generados

  • icon32.png - Ícono mediano (32x32)
  • icon48.png - Ícono grande (48x48)
  • icon128.png - Ícono extra grande (128x128)

  • icon32-active.png - Versión activa mediana
  • icon48-active.png - Versión activa grande
  • icon128-active.png - Versión activa extra grande
